# Оператор

Сетевая FPV-игра на Godot 4.7 (GDScript) для лаунчера Sevensave. Подробности — README.md.

## Правила

- Сеттинг: условная война без реальных стран, флагов, эмблем, названий армий и конфликтов. Стороны — только цвет и позывной.
- Никаких сторонних ассетов: геометрия, текстуры и звук процедурные.
- Тексты интерфейса, README, CHANGELOG, заметки к релизу и коммиты — на русском.
- `sim/` общий для сервера и клиента: без узлов сцены и рендера, только RefCounted/статические функции. Любая правка физики — с тестом в `tests/`.
- pid ботов на сервере отрицательные, «нет игрока/ничья» — 0 (не -1).
- Сервер не доверяет клиенту: всё входящее проверяется в `server/server_main.gd`/`server/room.gd` (`Proto.dict`, `Proto.clean_text`, клампы).
- Снапшот должен помещаться в UDP-пакет (< 1200 байт на 8 дронов) — есть тест.

## Проверка перед коммитом

```bash
./tools/check.sh && ./tools/test.sh && LIVES=1 ./tools/smoke_bots.sh
```

Графику смотреть скриншотами: `godot --path . -- --training --autopilot --seed1 --shot=/tmp/a.png --shot-at=14`.

## Релиз

Каждая заметная игроку правка — запись в `CHANGELOG.md` в разделе следующей версии. Версия совпадает в `project.godot`, `net/config.gd` (`GAME_VERSION`) и теге `vX.Y.Z`. Перед первым релизом в `net/config.gd` должен стоять адрес боевого сервера (release.yml это проверяет).
